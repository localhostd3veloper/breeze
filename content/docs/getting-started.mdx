# Getting Started

Breeze runs entirely on your own hardware. This guide walks through the
frontend, the backend, and the local model.

## Prerequisites

- **Bun** for the frontend
- **Python 3.10+** for the backend
- **MongoDB** (local or Atlas)
- **Ollama** running locally with chat and vision models pulled

## 1. Frontend

```bash
bun install
bun run dev
```

Copy `.env.example` to `.env.local` and fill in your values:

```bash
OLLAMA_API_URL=      # FastAPI backend URL, e.g. http://localhost:8000
OLLAMA_API_KEY=      # Shared secret for backend X-API-Key
MONGO_URI=           # MongoDB connection string
NEXTAUTH_SECRET=     # JWT secret
NEXTAUTH_URL=        # App URL
PLATFORM_PASSWORD=   # Demo account password
```

- `OLLAMA_API_URL` points at the FastAPI backend, not at Ollama directly.
- `OLLAMA_API_KEY` must match `API_KEY` in the backend's `.env`.

## 2. Backend

```bash
cd backend
python main.py       # FastAPI server on port 8000
```

Create `backend/.env`:

```bash
API_KEY=             # Shared secret, must match frontend OLLAMA_API_KEY
TAVILY_API_KEY=      # Optional: only needed for web search
```

The backend authenticates requests with the `X-API-Key` header. Rate limits
are applied per endpoint and per client IP: 10/minute on completion and
20/minute on summarize.

## 3. Model

Breeze talks to Ollama's OpenAI-compatible endpoint. By default that is
`http://localhost:11434/v1`. Pull the models you plan to use:

```bash
ollama pull phi4-mini       # default chat
ollama pull gemma3           # vision + generative UI
ollama pull qwen3            # reasoning
ollama pull qwen2.5          # web search
```

You can override the base URL with `OLLAMA_BASE_URL` in `backend/.env`.

## 4. Verify

Open `http://localhost:3000/chat` in your browser and send a message. The reply
streams in from your local model.

Check the backend is healthy with:

```bash
curl http://localhost:8000/health
```
