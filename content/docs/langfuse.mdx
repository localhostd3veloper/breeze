# Langfuse

Langfuse gives you end-to-end observability over every LLM call. Breeze wraps
its OpenAI client with Langfuse's auto-instrumentation, so every chat stream
and summary shows up in your project **without any code changes**.

## How it works

Breeze imports the OpenAI SDK through `langfuse.openai`. That wrapper
automatically records each model call as a trace. The LLM layer is therefore
instrumented even when you have not set a Langfuse project, in which case a
no-op tracer steps in and nothing is sent.

## Configuration

Add the Langfuse credentials to `backend/.env`:

```bash
LANGFUSE_SECRET_KEY=
LANGFUSE_PUBLIC_KEY=
LANGFUSE_BASE_URL=   # e.g. https://cloud.langfuse.com
```

Breeze only enables tracing when **both** the secret and public keys are set.
If they are missing, you will see a warning about tracing being disabled.

## Trace attribution

Two optional HTTP headers pass user and session context from the Next.js
proxy to the backend:

- `X-User-Id` attributes the trace to the signed-in user.
- `X-Session-Id` groups traces for one conversation into a session.

`/api/chat` reads these off the incoming request and re-adds them on the
upstream call, so they survive the proxy hop. The frontend sets them from the
NextAuth session and the conversation id.

## What is traced

- **Chat streaming** runs under the trace name `chat.stream_responses`, with
  the user id and session id attached via `propagate_attributes`.
- **Web-search tool calls** run under `tools.stream_responses` on the second
  pass, so you can see the search round trip and the final answer as one flow.
- **Summarisation** is traced through the wrapped client.

## What you can do with it

- See model, latency, and token usage per reply.
- Follow a single turn from prompt to tool call to final answer.
- Attribute usage to a user and a conversation.
- Debug why a reply skipped generative UI or fell back models.

## Caveats

- Ollama silently ignores `options.num_ctx`, so token counts and context
  limits are what the model actually used, not what the request asked for.
- The Langfuse credentials in your local `.env` are live secrets. Keep them
  out of version control.
